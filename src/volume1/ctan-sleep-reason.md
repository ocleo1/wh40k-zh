# C‘TAN们转入长眠的原因

boltgun

按照资料里看，C‘TAN们转入长眠的原因是他们的食粮都没了。

具体是这样

天堂之战时代最后，C’TAN的敌人OLD ONES势力里最恐怖种族，完全亚空间生物ENSLAVER，它们是一种在亚空间内寻找智慧生物的精神，然后伺机占领，从而占领其身体的一种生物。一旦一只生物的身体被它们占领，那么它的身体就成为了ENSLAVER们的通道，周围的生物会迅速被它们集体附体。（具体方法和过程没说）这个过程发生得极其迅速有效，蔓延速度极广，效率极高，当时被城为ENSLAVER瘟疫。后来这些亚空间生物显然失去了节制，搞得整个银河的生物族群几乎灭绝。OLD ONES应该也是消亡在它们手里。

这样，食物不足之后，C‘TAN们急速建造了自己的隐蔽星墓，在里面进行休眠，以求生命在银河再次繁荣起来时再醒来吃。

而CHAOS，说起来，就是天堂之战的大战时期，OLD ONES阵营中对异能也就是亚空间能量的利用达到了一个高峰，如此，相当频繁的负面情感在亚空间内大量成型，并在异能大规模使用的搅动下，开始凝结成一个个负面精神结成的亚空间生命体。这个应该才是CHAOS生物的崛起。（虽然没有“就是如此”这样程度的说法，但是有七成的可能）。如此一看，OLE ONES们应该为CHAOS诞生付相当的责任。
