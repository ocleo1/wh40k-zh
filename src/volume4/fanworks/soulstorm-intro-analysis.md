# 灵魂风暴片头再考——这次好好分析了

灵魂风暴片头再考——这次好好分析了...

塞戈德

灵魂风暴片头有一个细节，就是老户被渔民干死后被修女姐姐踩了尸体，要知道一个对帝国有功的将领是不应该受到这种歧视的，理应受到厚葬。

客观原因可以能2条：

1.修女明显与IG的关系不好。

2.或者说是跟老卢私人间有恩怨。

我参考了一些文献，审判庭相比SM通常更亲近与IG，而且身边人这么多，对于一个已死的人做出如此不敬的举动很可能会被申报。

所以这2条原因都很难站主脚。

任何原因都不剩下了吗？难道relic仅仅是为了让修女姐姐们耍帅？

不，还有一个重要原因——修女是做什么的？

修女是异端审判庭的直属部队，又译做异教徒审判庭是帝国内部用来调查和审判对皇帝不忠有二心的审判庭，可以说事实上给IG做援军、去打渔民这种事情根本不由她们负责。

如果由审判庭出面增援也应该是由外星人审判庭的特殊部队——死亡守卫战团来增援。

那么修女为何会到IG的阵地上？

答案显然只有1个，来调查或审判卢卡斯的。

大家如果玩过DC战役的话，无论用卢卡斯或者SM赢了战役的话，战役最后都会说他们相互找审判庭调查对方。

另外建议参考一下这个帖子http://zhihuiguan.com/bbs/read.php?tid=9175

血鸦战团的简介。

“他们在审判庭以及战斗修女团的纯理论研究组织中也有着极高的声望。”

至少可以这样说，这是非常不正常的，因为就算是自己组织的分支机构，审判庭也很少信任到这种程度，而且星际战士和Ecclesiarchy的传统矛盾使合作研究成为一种罕见的事。事实上，与那些在不同时期有着上千年不和（似乎是说与帝国其他机构的问题）的其他的星际战团相比恰恰相反，血鸦看起来似乎与帝国的各种权利机构有着非同一般的关系（如审判庭，帝国卫队，Ecclesiarchy等）。

————————————————

血鸦战团与审判庭的关系相当融洽，在作战的同时还经常会与审判庭共同研究某些课题，可以说是帝国绝对信任的存在。

那么很明显的，最终的审判结果一定是对老卢不利的，所以派修女来调查老卢是理所应当的。

所以我推测其实修女很早之前就已经在阵地上了，甚至已经与老卢交谈过了，有3个细节可以真实，首先是修女出现的时候，并没有作为援军急行军跑步中那种状态，并且是从阵地后方直接上前，而不是阵地侧面或者敌军的身后。其次老卢在开头的战吼中对士兵喊的是“为自己而战，我们必须赢”战吼中并没有夹杂皇帝、吾皇、圣恩等字眼。我猜测老卢此话的意义是“为自己（的清白）而战”，在被调查的军士或许已经被剥夺了呼喊皇帝之名的权利。

最后有一个细节，就是IG的军中没有政委，政委是代表皇帝的意志，一旦作为有异端嫌疑的军队，政委可能会被撤去？（这条我不确定）

————————————

好，我来简述一下推理出的事实经过。

DC战役的事实结局无论是怎样，老卢与血鸦一定是已经有所冲突了，而结果是血鸦占据了上风，异端审判庭派遣战斗修女去老卢的阵地进行调查，正与老卢交涉的同时，渔民正好来攻打阵地。

作为还没定罪仍效忠于帝国的老卢必然要做出反击，同样这也能是洗请自己嫌疑的做法。修女是负责对异端的，对外作战不归她们管，所以自然也不会插手，先放任老卢打退敌军。

但是老卢跟IG士兵看到异端审判庭来了，心里肯定多少会有些不好受。所以士气大受打击，又没政委，所以被渔民灭了干净~

战斗修女虽然不负责对外作战，但是看到皇帝的领地即将失守，肯定还是坐不住的。

她认为老卢是浪得虚名，所以才踩了他。
